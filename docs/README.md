## Examples

You can import [Orbital Courier](examples/orbital-courier.json) to try all the
shapes, unions, subtractions, and intersections. Click **Reset view** after importing it, then
select **Scene** to hide the gizmos.

To try the polygon editor, expand **06 · Courier → Polygon fins** and click the
pen on either fin.

Import [Clipped star](examples/clipped-star.json) for a simple Clip example.
